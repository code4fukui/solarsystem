# Simple Solar System Simulator

Three.js で作った、単一 HTML ファイルの太陽系シミュレーターです。通常の3D表示に加えて、対応環境では WebAR 表示も使えます。

## 機能

- ドラッグで視点回転、ホイールでズーム。
- 公転アニメーション速度を調整可能。
- 表示モードを切り替え可能:
  - デフォルメ: 見やすさ優先で距離と天体サイズを誇張。
  - リアル: 距離、天体サイズ、月周回軌道を同じ AU ベースのスケールで表示。
- 日本語ブラウザ環境では、太陽と惑星名を日本語で表示。
- 水星と冥王星の軌道傾斜に対応。
- WebAR 対応環境では、背景が透ける AR ボタンを表示。
- AR 表示時の太陽系サイズを 1m から 30m まで選択可能。

## 起動方法

任意の静的 HTTP サーバーでこのディレクトリを配信します。

```sh
python3 -m http.server 8000
```

ブラウザで以下を開きます。

```text
http://localhost:8000/index.html
```

## 補足

WebAR には WebXR `immersive-ar` に対応したブラウザと端末が必要です。非対応環境では通常の3Dページとして動作します。

リアル表示モードでは物理スケールを揃えているため、惑星は軌道距離に対して非常に小さく表示されます。
